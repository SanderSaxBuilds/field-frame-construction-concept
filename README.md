# Field & Frame construction website concept

A responsive website for a fictional local builder, designed and built by Alexandr Khrustalev.

Field & Frame is fictional. This is not a past client project, and no construction services are offered.

## What it shows

- A builder home page with a clear quote path: services, project sheets, a four-step process and common questions
- A mobile menu that traps focus while open and closes with Escape, an outside click or a wider window
- A project brief planner with validation that builds a text file on the visitor's device and sends nothing
- Plain HTML, CSS and JavaScript with no build step, checked at 320, 390, 768, 1024 and 1440 pixels

## Files

- `index.html`, `style.css` and `app.js` are the site
- `house.jpg` is the licensed hero photo
- `project-brief.txt` lists what a real client project would need to confirm before launch
