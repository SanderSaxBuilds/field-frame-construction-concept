# Field & Frame construction website concept

An independent responsive portfolio concept by Alexandr Khrustalev.

Field & Frame is fictional. This is not a past client project, and no construction services are offered.

## Demonstrated work

- Responsive HTML and CSS implementation
- Service and process presentation
- Keyboard-visible navigation and semantic structure
- Clear portfolio disclosure and licensed image attribution
- A non-collecting enquiry concept with a downloadable project brief
